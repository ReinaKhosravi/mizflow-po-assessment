# Tables

The operational نارون hall has twelve active physical tables labeled ۱–۱۲: eight four-seat rectangles and four two-seat circles. A responsive illustrative hall view sorts Persian/Latin numbers naturally and filters all/free/occupied/awaiting-order tables. Choosing a table opens its scoped order.

Seating/menu presentation creates a draft record and occupies the table before food is submitted. Ready food is explicitly served per item by waiter/owner. The table stays occupied after delivery until confirmed guest departure closes the service; another party then gets a new order. Empty draft parties can also depart. Unserved food prevents closure. Additional rounds preserve earlier served rows. Database locks, versions and unique active-order index are authoritative; no payment operation is implied. See HANDOVER.md.
